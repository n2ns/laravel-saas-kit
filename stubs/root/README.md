# SaaS Starter

Laravel 12 product site generated by
[`n2ns/laravel-saas-kit`](https://github.com/n2ns/laravel-saas-kit). The
installer copied a complete application into this repository; from here on the
site owns every file and should replace the starter identity, product, plans,
legal copy, assets, OAuth credentials, and Stripe IDs with its own.

## What the Site Includes

- **Marketing pages**: home, about, support, privacy, terms, refund, account
  access, get started, account, 404, and 503 pages with header/footer
  navigation.
- **Product catalog**: `/products`, catalog detail pages at `/{slug}`, product
  privacy pages at `/{slug}/privacy`, and pricing pages at `/{slug}/pricing`,
  all driven by database records edited in Filament.
- **Blog**: `/blog` with search, type/topic filters, and sorting; article pages
  at `/blog/{slug}` with related posts; file-based seed content and an
  API-key-protected management API. See [BLOG_GUIDELINES.md](BLOG_GUIDELINES.md).
- **Multilingual routing**: English without a URL prefix, plus `/es`, `/de`,
  and `/cn` (`zh_CN`) prefixes configured in `config/app.php`
  (`supported_locales`).
- **SEO**: canonical URLs, `hreflang` alternates, Open Graph/Twitter tags,
  JSON-LD structured data, a `/robots.txt` route, `public/llms.txt`, and
  `php artisan sitemap:generate`.
- **Authentication**: Google web login (Socialite), Google One Tap, external
  client API login with Google ID tokens through Passport, refresh tokens,
  device sessions, `auth_epoch` revocation, one-time-token (OTT) web login, a
  JWKS endpoint, and API keys. See [API_AUTH.md](API_AUTH.md).
- **Billing**: Stripe Checkout (subscriptions, lifetime, and one-time credit
  packs), Stripe webhooks, Customer Portal, orders, subscriptions, plans, and
  credit grants.
- **User dashboard**: `/dashboard` with overview, subscriptions, orders, and
  settings tabs.
- **Analytics**: privacy-preserving daily page-visit and click-event counters,
  plus per-product usage event APIs.
- **Filament admin** at `/{ADMIN_PATH}` (default `/admin`): operations
  dashboard, access analytics, users, user sessions, catalog items, homepage
  display, product listings, plans, subscriptions, orders, Stripe webhooks,
  blog posts, post translations, payment gateways, and API keys.
- **Starter data**: `ReferenceDataSeeder` creates one `starter` catalog item
  and product, Free / Plus / 10 Credits plans, and the Stripe payment gateway;
  `BlogPostSeeder` imports two starter articles.

Product-specific business workflows, provider integrations, and production data
are not included. Add them to this site.

## Local Setup

Requirements: PHP 8.3+, Composer, Node.js with npm, and SQLite for the default
local configuration.

```bash
composer install
npm install

cp .env.example .env
php artisan key:generate
php artisan passport:keys

touch database/database.sqlite
php artisan migrate
php artisan passport:ensure-social-client --create
php artisan db:seed

npm run build
php artisan serve
```

In a second terminal, run the queue worker. Stripe webhooks, product usage
events, and the subscription activation email are queued jobs:

```bash
php artisan queue:listen
```

Use `npm run dev` instead of `npm run build` for Vite hot reloading.

- `php artisan db:seed` runs `DatabaseSeeder`, which calls
  `ReferenceDataSeeder` and `BlogPostSeeder`. Use
  `php artisan db:seed --class=ReferenceDataSeeder` to seed only the starter
  product, plans, and gateway.
- `passport:ensure-social-client --create` prints
  `PASSPORT_PASSWORD_CLIENT_ID` and `PASSPORT_PASSWORD_CLIENT_SECRET`. Copy
  both into `.env` before using API login.

Set these before testing login or payments:

```dotenv
APP_URL=http://localhost:8000

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
# Optional override. Defaults to APP_URL/auth/google/callback.
# GOOGLE_REDIRECT_URI="${APP_URL}/auth/google/callback"

STRIPE_KEY=
STRIPE_SECRET=
STRIPE_WEBHOOK_SECRET=
STRIPE_PORTAL_CONFIGURATION=

STARTER_STRIPE_PRODUCT_ID=
STARTER_PLUS_MONTHLY_STRIPE_PRICE_ID=
STARTER_CREDITS_10_STRIPE_PRICE_ID=

PASSPORT_PASSWORD_CLIENT_ID=
PASSPORT_PASSWORD_CLIENT_SECRET=

ADMIN_EMAILS=
```

`ReferenceDataSeeder` reads the `STARTER_*` Stripe IDs when it writes the
`products` and `plans` rows. If you set them later, update the records in
Filament or re-run the seeder.

### Admin Access

A user can open the Filament panel when `users.is_admin` is true or the user's
email is listed in `ADMIN_EMAILS` (comma-separated; falls back to
`ADMIN_EMAIL`). Sign in on the public site with Google using that email, then
open `/{ADMIN_PATH}`.

## Common Commands

The installer merged only `autoload` entries and `config.allow-plugins` into
this site's `composer.json`; its Composer scripts and dev dependencies are the
host Laravel application's own. The commands below do not rely on custom
Composer scripts.

| Command | Purpose |
|---|---|
| `php artisan test` | Run the test suite. |
| `bash scripts/run-local-tests.sh` | Run tests in parallel (`php artisan test --parallel`; needs the `brianium/paratest` dev package). |
| `php scripts/lint-php.php` | PHP syntax check of the project, skipping `vendor` and `node_modules`. |
| `./vendor/bin/pint` | Format PHP with Laravel Pint (`--test` to check only). |
| `./vendor/bin/phpstan analyse` | Static analysis with the bundled `phpstan.neon`; needs the `larastan/larastan` dev package. |
| `composer audit --no-dev` | Check installed production dependencies for advisories. |
| `npm run build` / `npm run dev` | Build frontend assets with Vite, or run the Vite dev server. |
| `php artisan queue:listen` / `php artisan queue:work` | Process queued jobs (Stripe webhooks, product usage, mail). |
| `php artisan sitemap:generate` | Write `public/sitemap.xml`. |
| `php artisan translations:check [--locale=]` | Report catalog and blog translation coverage. |
| `php artisan catalog:export [--pretty] [--path=] [--record]` | Export catalog data as JSON. |
| `php artisan passport:ensure-social-client` | Verify the Passport API client grant types. |
| `php artisan app:sync-product-stats` | Refresh GitHub/npm/VS Code stats stored in product metadata. |
| `php artisan seed-data:export` | Export database rows to `database/seeders/data` for `SeedDataSeeder`. |
| `php artisan database:restore-local --force` | Rebuild the local MySQL database from migrations and exported seed data. |
| `php artisan database:restore-seed-data` | Same rebuild for local/testing, or production with `--allow-production`. |
| `bash scripts/deploy-production.sh` | Routine production deployment. |

`routes/console.php` defines no scheduled tasks. Run `sitemap:generate` and
`app:sync-product-stats` manually or add them to the scheduler.

Tests use in-memory SQLite (`phpunit.xml`). Migrations create MySQL/MariaDB
fulltext indexes only on non-SQLite connections, and blog search falls back to
`LIKE` matching on SQLite.

## Operating Model

Use the admin panel to replace the starter catalog item, product, plans, blog
posts, and SEO fields with the site's own content. Static page copy and legal
text live in `resources/views` and `resources/lang`.

Product-specific code belongs in this site. Improvements that every product
site should share belong in the `n2ns/laravel-saas-kit` installer stubs.
